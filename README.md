# 🔱 NeuraforgeAI Hub - go.botcaza.ai

Ecosistema centralizado de intercambio de información, inteligencia y monedas digitales.

## 🚀 Despliegue
1. Configurar `.env` con tus credenciales.
2. Ejecutar `pip install -r requirements.txt`
3. `python main.py`

## 📦 Módulos
- **Bot Monetízame**: Vende, renta o subasta objetos con IA.
- **Motor de Pagos**: Bitso, Binance, Mercado Pago.
- **Guardián de Errores**: Afiliados y soluciones técnicas.
- **Mini App Web**: Panel de usuario.

## 🌐 Dominio
`go.botcaza.ai` - Centro de intercambio global.
